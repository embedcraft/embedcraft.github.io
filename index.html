Featured Project

Proof, not a portfolio

We don't have client case studies yet — so here's something one of us built, in detail.

Wireless Vibration & Temperature Monitoring Node

A predictive-maintenance sensor node, built from scratch

Condition monitoring starts with getting reliable sensor data off the machine. This demo — built by our co-founder Rajbir as a personal project — streams vibration and temperature readings from an ESP32-based sensor node to a live cloud dashboard, the same pattern we'd use to prototype an industrial condition-monitoring product for a client.

  • Accelerometer + temperature sensing over I2C
  • Sampling and buffering handled on-device before publish
  • Wi-Fi telemetry pushed to a live dashboard, no gateway hardware needed

About

Two engineers, one studio

EmbedCraft Systems is run by two embedded engineers who've spent their careers building firmware other people's products depend on, and are now doing it under our own name.

Lakhbir Singh
Co-founder

10+ years leading embedded teams, most recently architecting the wireless control and sensor pipeline for a consumer action camera. Before that: industrial PLC/SCADA gateways speaking Modbus and IEC-104, and a government-compliant vehicle tracking system built to AIS-140 spec. Deep in STM32 and ARM Cortex-M, RTOS scheduling, and the unglamorous stuff — bootloaders, OTA, driver bring-up — that decides whether a product survives the field.

"If it hasn't been measured on a bench with a logic analyzer, it isn't done — it's a guess."
Rajbir Singh
Co-founder

Embedded IoT engineer with a track record of taking sensor data from raw registers to a cloud dashboard — BLE product firmware on nRF52832, ESP32 and LoRa sensor networks, and AWS IoT / Azure integrations for condition-monitoring and energy-metering systems. Writes up side projects on Hackster and Medium in the time between them.

"Give me a datasheet and a logic analyzer and I'll have two devices talking to each other by end of day."
